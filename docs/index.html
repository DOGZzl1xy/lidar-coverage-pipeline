Why there are two numbers

The hobuinc inventory lists only the 3DEP collections that have already been converted to Entwine Point Tiles. When I spot-checked towns with 0% coverage, several had modern data in the official USGS 3DEP index that the inventory does not list yet. Concord, NC has NC_Phase4_Cabarrus_2016, New Ulm, MN has MN_RiverEast_2_B23, and Colonial Heights, VA has VA_SouthamptonHenricoWMBG_2_2019. Meredith township, NC has only 2001 data in both sources, so it remains a gap.

The pipeline can now run with or without the official index. Which result to treat as primary is still an open question.

Method

  • Boundaries come from the Census TIGER/Line 2024 county subdivision files. Placeholder areas coded 00000 ("County subdivisions not defined", mostly water) are excluded.
  • Footprints are unioned in EPSG:5070, so overlapping collections are not double counted. A gap is coverage below 5%.
  • A collection counts as modern when its latest acquisition year is 2015 or later, so collections that span 2015 count as modern.
  • Most vintages come from collection names. I reviewed 53 collections with conflicting or missing dates one by one, checking USGS, OpenTopography, NOAA and state records and, where needed, GPS times sampled from the point clouds (5 to 65 MB per collection). The evidence for each decision is saved with the code.
  • Each run downloads the latest inventory and records the input hashes and parameters, so any result can be traced back to its inputs.

Read with care

Minnesota's Gen2 LiDAR (2021 to 2024) and KyFromAbove Phases 2 and 3 (2024 to 2026) are not fully included in the USGS sources, so some MN and KY gaps may already be covered by state data. The MN and KY outputs say so.

The 3DEP supplement takes official dates at face value for everything outside the 53 reviewed collections. Its footprints are also generalized to about 50 m, which can shift coverage slightly for towns near a collection edge.

The hobuinc inventory is updated almost daily, so runs on different days can differ slightly.

Height fusion tool

The separate package that fuses Meta canopy height with Overture building heights now writes GeoTIFFs either locally or to S3, and can export layers for checking in QGIS. Its 14 offline tests pass, and a Hong Kong sample ran end to end (934 × 1008 grid, 438 buildings). Next, I plan to validate it on several of the gap towns above and on a few Global South cities.
